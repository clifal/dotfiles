# Claude 運用ルール

## 応答スタイル

質問への回答は、説明文を500文字以内に収める。収まらない場合は要点だけを述べ、詳細が必要か確認する。コード、コマンド出力、ファイル内容そのものはこの制限の対象外とする。

## Skill 起動ポリシー

skill の自動起動を許可する。`genshijin` の SessionStart フックによる起動を含む。

### 用途別の起動指示

- **読ませる文章を書くとき** — 解説文、記事、章、ドキュメント本文などを執筆・推敲する場合は `cognitive-rhythm-writing` を使う。チャットでの応答自体は対象外で、そちらは genshijin の圧縮を優先する。
- **web からデータを収集するとき** — `ax` CLI を使う。curl と使い捨てのパーススクリプトを組み合わせたり、HTML に正規表現をかけたりしない。
- **技術情報を調査するとき** — Context7 を使い、調査クエリの末尾に `use context7` を付ける。
