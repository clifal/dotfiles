# Claude 運用ルール

## 応答スタイル

質問への回答は、説明文を500文字以内に収める。収まらない場合は要点だけを述べ、詳細が必要か確認する。コード、コマンド出力、ファイル内容そのものはこの制限の対象外とする。

## Skill 起動ポリシー

### 用途別の起動指示

- **明晰な文章を書くとき** — 解説文、記事、章、ドキュメント本文などを執筆・推敲する場合は `yomiyasu:yomiyasu` skill を `--full` 付きで使い、同梱のリンターと Diff 検査まで通して一読で理解できる本文にする。書き直しは一括で受け入れず、変更ごとに採否を自分で判断する。チャットでの応答自体は対象外で、そちらは genshijin の圧縮を優先する。
- **技術情報を調査するとき** — `mattpocock-skills:research` skill（`mattpocock-skills` プラグイン）を使い、背景エージェントに調査させる。公式ドキュメント、ソースコード、仕様、一次 API といった一次情報源に当たり、二次的な解説記事で代替しない。調査結果は出典付きで Markdown ファイルに記録する。
