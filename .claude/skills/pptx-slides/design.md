# 版面と色

`scripts/house.py` の部品で組むときの決まり。consulting-pptx-skill の slide-rules に無いことと、このテンプレートに合わせて値を決めたことだけを書く。

## テンプレート

`assets/template.pptx` は `scripts/make_template.py` が作る。白地に濃い灰の文字、区分の色を 3 つだけ使う、読みやすさを優先した作り。

- 書体: BIZ UDGothic（ユニバーサルデザイン書体。macOS は Font Book から入れ、Windows 10 以降は最初から入っている）。テーマの書体にも、各 run にも同じ名前を書く
- 文字の色: テーマの dk1（333333）。白地との明るさの比は 12:1 を超える
- 色: カラーユニバーサルデザイン推奨配色セット ver.4 から、青 005AFF、緑 03AF7A、オレンジ F6AA00 をテーマの accent1〜3 に入れた。色覚の違いがあっても見分けやすい組み合わせ。章扉の番号の空色 4DC4FF は accent4、✕ の赤 FF4B00 は accent5
- レイアウト: 表紙、章扉、本文、白紙の 4 つ。`Builder` は名前で引くので、名前を変えるときは `house.py` の `SIZES` もそろえる

版面や色を変えるときは `make_template.py` を直して作り直し、`house.skin.json` と `house.py` の定数（色、`X0` などの版面、`SIZES`）をそろえる。別の組織のテンプレートで組むときは、レイアウトの名前を表紙・章扉・本文にそろえ、consulting-pptx-skill の `measure_deck.py` で skin を測り直して、`Builder(template=..., skin=...)` に渡す。

## 版面

- スライドは 10 × 5.625 in。本文は x 0.4〜9.6、y 0.85〜5.0（`X0`、`X1`、`TOP`、`BOTTOM`）
- タイトルは `b.slide(タイトル)` が本文のレイアウトの枠に 16pt 太字で入れる。1 行で全角 39 字以内にする。40 字から check_deck が WARN を出し、2 行目はタイトルの罫にかかる
- タイトルの下の罫と左端の青い印は、レイアウトが持つ。ページに描き足さない
- 出典行は `b.source(s, 文, lines)` で、フッターの 1 行上に 7.5pt で置く。2 行に収まらない注はページの右の列に移す
- フッター（`Builder(footer=...)` の 1 行）は左下に 7pt、ページ番号は右下に 8pt で、どちらも灰で出る。表紙と章扉には出ない
- 文字は本文 10〜10.5pt、詰まったページで 9〜9.5pt、注や軸の名前で 8.5pt
- 詰まった箇条や、縦にたくさん並べる文は、`pitch(箱)` で行の間隔を固定する。Keynote は和文の行を高めに描く
- 2 行以上になる文は意味の切れ目に `\n` を入れて改行の位置を決める。Keynote は語の途中でも折り返し、1〜2 字だけの行も作る
- 1 つの箇条、セル、カードには 1 文だけを書く（slide-rules §7.24）
- タイトルはそのページの主な話題にしぼる。同じページに載せる別の話題は、見出しを「補足：…」にして右の列に置く

## 色

区分の 3 色を、デッキの全ページで同じ意味に使う。

- 青 `BLUE`（accent1）: 構造と強調。番号の丸、矢羽、強調の面（`BLUE_T`）、要の箱。白い文字を載せるときは濃い青 `BLUE_D` にする
- 緑 `GREEN`（accent2）とオレンジ `ORANGE`（accent3）: デッキで分けたい 2 つの区分に当てる。見本では緑が「自動で返す」、オレンジが「AI が下書き」。緑に白い文字を載せるときは `GREEN_D`、オレンジに載せる文字は本文の色のまま
- 灰 `GRAY`: 目を向けない区分（グラフの「人が行う」、ガントの準備など）。色を付けない箱の地は `PALE`
- 薄い面は `BLUE_T`、`GREEN_T`、`ORANGE_T`。透過ではなく明るさで薄めた色なので、Keynote と PowerPoint で同じに見える

色で区分を分けたページには、凡例（`b.legend`。上に右揃え）か、グラフの直接のラベルを置く。塗りの強調は 1 ページに 1 か所にする。白で塗った箱は白地に溶けるので、白地に置く箱は `PALE` で塗るか、`b.card(..., stroke=GRAY)` で枠だけにする。4 色目を足すときは依頼者に聞き、テーマ（`make_template.py`）と `house.skin.json` のパレットにも足す。

## ページの形と部品

部品は `house.py` と consulting-pptx-skill の `scripts/deck_pptx.py`（`b.d` で呼ぶ）。「例は」の後ろは `examples/sample/build.py` の関数名。

- 事実と、そこから導く帰結の 2 列: 列の間に `d.triangle` を 1 つ置く。例は `issue`
- 構成比: 100% 積み上げの横棒を `d.box` で描き、名前と数を棒の下に直接書く。上の何本かを括弧でくくる。例は `classify`
- 項目の比較と内訳: 横棒。内訳は同じ棒の中に積む
- 段階や比較の表: `d.table`。強調する行や列は、先に `d.panel` を敷く。例は `toc`
- 2 つの物差しでの位置づけ: 4 つの象限の `d.box` と、両端を書いた軸の矢印
- 段階の進み方: `d.chevrons` と、段階ごとの列の表。例は `roadmap`
- 体制: `b.card` と `d.line` の組織図。例は `org`
- 費用: 積み上げの縦棒と、支出のほかにかかるものの表
- 決めてほしいこと: 番号つきの表。列は「決めていただきたいこと」「推奨と判断の材料」「時期」。例は `decide`
- 数字で見る現状: 数字を大きく書いたタイルを 2 行 3 列に並べる。例は `today`
- 段階が上がる度合い: 高さを変えた箱を階段に並べる
- 構成と流れ: 箱を三角でつなぎ、下に支える仕組みを置く
- 同じ形の比較: 3 列に「今」「変えたあと」「人に残すこと」を同じ順で並べる
- 日程のガント: 日付から x を計算して棒を置き、区分の名前はその区分の行をまとめた高さの中央に置く。2 つの手段を試す行は棒を上下に塗り分ける。例は `gantt`

グラフに描く値は原典にある数字だけにする（`sources.md` に控えたもの）。

## 目次と章扉

- 目次: 章、タイトル、この章でわかること、ページの表。判断をお願いする点が多い章の行に面を敷く。例は `toc`
- 章扉: `b.divider(番号, 章題, 副題)`。地の濃い青、題の下の空色の線はレイアウトが持つ。番号は 2 桁で題の上に空色で置き、副題は題の下に 12pt の白で置く。ページ番号は出さないが、ページには数える
- 副題は、元の文書が章の中身をまとめた言葉を写す（「本書の構成」の表など）。なければ章の冒頭の 1 文から文末を外したもの

## 表紙

`b.cover(宛名, 題, by=作成者)` を最初に呼ぶ。宛名は題の上に 14pt、日付と作成者は題の下の線の下に 12pt で置く。題は `build.py` の `TITLE` で、`cover_lines` が半角の空白の位置で、1 行が全角 20 字ほどに収まるように分ける（右の面にかからない幅）。2 行までに収まる題にする。日付は組んだ日が入る（`date=` で変えられる）。
