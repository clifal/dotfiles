# 前の版との差分

デッキの PDF を前の版と比べ、文言が変わった行に枠を付けて左右に並べた PDF（差分の PDF）と、行の差分の Markdown を作る。PR のレビューで main と比べるときと、前に渡した版と比べるときに使う。

## 1. 比べる版を決める

- デッキのフォルダが git にあるとき
  - PR のレビュー: 前の版は main との分かれ目、後の版はデッキのフォルダの PDF
    - 分かれ目は、`git fetch origin main` のあとの `git merge-base origin/main HEAD`
  - 前に渡した版との比較: 前の版は渡したときのコミット。会話や `qa.md` から分からなければ依頼者に聞く
- git にないとき: 前の版の PDF の場所を依頼者に聞く

後の版の PDF は、今の PPTX から書き出したものにする。PDF が PPTX より古ければ（`[ "<pdf>" -nt "<pptx>" ]` が偽なら）、先に SKILL.md の 6 と 7 を回す。

版の名前は、差分の PDF の表紙と見出しに出る。

- 前の版: `main（<短いハッシュ>）`。渡した版なら `<渡した日> に渡した版` にし、コミットがあれば短いハッシュを括弧で添える
- 後の版: PDF がコミットと同じなら（`git diff --quiet HEAD -- "<pdf>"` が真なら）`PR #<番号>（<短いハッシュ>）`。違えば `PR #<番号>（<短いハッシュ> と未コミットの直し）`。PR がなければ番号の代わりにブランチ名を書き、git にないときは `今の版` にする

「差分を更新」と頼まれたときも、ここから決め直す。main や PR のコミットが進んでいることがある。

完了: 前の版の PDF、後の版の PDF、2 つの版の名前が決まった。

## 2. 差分を作る

前の版の PDF は、git にあれば取り出す。題を変えた版と比べるときはファイル名が違うので、`git -c core.quotePath=false ls-tree --name-only <コミット> <デッキのフォルダ>/` で前の版の名前を確かめる（`-c core.quotePath=false` がないと、日本語の名前が `\351…` の形で出る）。

```sh
D=<スクラッチ>/pdfdiff/<デッキ名>
mkdir -p "$D"
git show <コミット>:"<デッキのフォルダ>/<前の版の題>.pdf" > "$D/old.pdf"
python3 -I ~/.claude/skills/pptx-slides/scripts/pdfdiff.py "$D/old.pdf" "<デッキのフォルダ>/<題>.pdf" "$D/out" "<前の版の名前>" "<後の版の名前>"
```

`git show` のパスは、リポジトリの最上位から書く（今いるフォルダからのパスなら、頭に `./` を付ける）。git にないときは、依頼者に聞いた PDF を `old.pdf` の代わりに渡す。前に作った出力先が会話にあれば、そこに上書きする。

完了: `$D/out/deck-diff.pdf` と `deck-diff.md` ができた。

## 3. 結果を確かめる

`deck-diff.md` の一覧と、ページごとの `-`（前の版にだけある行）と `+`（後の版にだけある行）を読み、一覧のすべてのページを次のどれかに分ける。

- 意図した変更: 依頼、`qa.md`、コミットの内容から、直したと分かるページ
- 意図しない変更: 直していないのに文言が変わったページ。PDF のそのページを見て、文言が変わったのか、改行や書体の変化で行が割れただけかを決める
- 見た目だけ: 書体、行の間隔、図の位置の差。多くのページに出たら、書き出しの環境（Keynote の版、書体）が前の版と違うことを疑う

足したページと消したページは、ページの追加と削除の意図と合うかを見る。合わなければ、対応づけの誤りかを PDF で確かめる。

表紙と、文言が変わったページを 1 枚以上、画像で見て、枠が行に重なっていることを確かめる。

完了: 一覧のすべてのページを、意図した変更、意図しない変更、見た目だけのどれかに分けた。意図しない変更があれば、依頼者に伝えた。

## 4. 伝える

`deck-diff.pdf` と `deck-diff.md` を、絶対パスを文字と宛先の両方にした Markdown のリンクで示す（`[/private/tmp/…/out/deck-diff.pdf](/private/tmp/…/out/deck-diff.pdf)` の形）。VS Code のチャットでは、押すとエディタで開く。宛先は `/` で始まるパスにする。`file://` の URL はチャットが宛先を消すので、押しても開かない。あわせて、文言が変わったページ、見た目だけ変わったページ、足したページ、消したページの数を伝える。

差分の PDF は作業用のファイルなので、スクラッチに置いたままにする。PR やほかの場所に載せるかは依頼者が決める。PR に添えるときは、依頼者がブラウザで PR の本文かコメントの欄に PDF をドラッグする。gh には添付の機能がない。

完了: 2 つのファイルのリンクとページ数を伝えた。

## 読み方と限界

- 枠は行ごとに付く。赤は前の版にだけある行、青は後の版にだけある行。線の太さは `pdfdiff.py` の `FRAME`（画素）で変えられる
- 改行の位置だけが変わった行と、書体や行の間隔だけの差には、枠が付かない
- 行の文字列が相手のページのどこかに含まれていれば、変わっていないと見なす。数字だけの短い行の変更は見落とすことがある
- ページは文言の近さで対応づける。書き直したページは同じ位置どうしで対になり、足したページと消したページだけが外れる。動かしたページは、消したページと足したページの組に出る
- ページ番号（上下の余白にある 3 桁までの数字だけの行）は比べない
- 図や画像だけの変更は、文言が変わらないので「見た目だけ」に入る
- 番号は後の版のもの。番号がずれたページは `P.13（前 P.12）` のように前の版の番号を添え、消したページは `前 P.n` で示す
